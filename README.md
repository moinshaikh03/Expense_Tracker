# 💰 Python Expense Tracker

A simple, beginner-friendly expense tracking application built using Python. It allows users to record daily expenses, view all recorded expenses, and calculate their total spending through a menu-driven interface.

## ✨ Features

- Add expenses with date, category, description, and amount.
- View all recorded expenses.
- Calculate total spending.
- Simple menu-driven interface.

## 🛠️ Technologies Used

- Python
- Lists and Dictionaries
- Loops and Conditional Statements
- User Input and Console Output

## 🚀 How to Run

1. Install Python.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python expense_tracker.py
```

## 📌 Note

Expenses are stored in memory and are not saved permanently. All recorded expenses will be lost when the program exits.
